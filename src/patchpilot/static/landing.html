SCOPE, WITHOUT GUESSWORK

A focused prototype.
A clear boundary.

Public HTTP observation comes first. The separate repair lab demonstrates controlled deployment changes on local fixtures.

Which websites can I assess?

Enter a public HTTP(S) URL on port 80 or 443, without credentials or query parameters. Private and reserved destinations are excluded. The server validates the destination and redirects.

Does assessment change the website?

Website assessment collects normal public HTTP responses and suggests remediation. Applying configuration or code requires your review and authorized access to the server. The separate repair lab has its own approval workflow.

How are findings supported?

Findings link to timestamped observations. Reports retain response metadata and hashes, PHP detection confidence, analysis provenance, coverage, and limitations. A completed assessment is not a declaration that a website is safe.

What is the repair lab simulation?

The separate lab plays a clearly labeled example of a controlled PHP fixture repair, including approval, verification, and recovery. Live website assessments always collect their own public response evidence.
